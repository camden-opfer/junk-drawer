## Junk Drawer
A bunch of random stuff. Currently includes...
- `bibFileNiceifier.py` a library and CLI-usable script for manipulating LaTeX bib files. To learn to use it, run `python bibFileNiceifier.py -h`
- `atmosphereBasics.py` for constants and simple functions related to atmospheric science
- `pythonUtils.py` has utility functions for backend Python things like logging
- `forBashrc.sh` contains aliases and functions that are nice to have in a ~/.bashrc file (in my opinion)
